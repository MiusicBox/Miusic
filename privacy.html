📜 นโยบายความเป็นส่วนตัว (Privacy Policy)

เวอร์ชัน: v1.0-20261007
วันที่มีผล: 7 ตุลาคม 2569
เจ้าของข้อมูล: Music Store (เว็บขายเพลง DJ Remix)

นโยบายความเป็นส่วนตัวนี้อธิบายวิธีที่เราเก็บ ใช้ และปกป้องข้อมูลส่วนบุคคลของท่าน ตามพระราชบัญญัติคุ้มครองข้อมูลส่วนบุคคล พ.ศ. 2562 (PDPA)

1. ข้อมูลที่เราเก็บ

เราเก็บข้อมูลดังต่อไปนี้เพื่อให้บริการสั่งซื้อเพลง:

ข้อมูลที่ท่านให้โดยตรง

  • ชื่อลูกค้า — ใช้แสดงในใบเสร็จและการสื่อสาร
  • เบอร์ WhatsApp — ใช้ติดต่อเรื่องออเดอร์ + ส่งลิงก์ดาวน์โหลด
  • อีเมล — ใช้สำหรับ login (ถ้าลูกค้าเลือก)
  • รหัสผ่าน — เก็บแบบ hash (PBKDF2) ไม่สามารถอ่านกลับเป็นข้อความเดิมได้
  • สลิปการโอนเงิน — ใช้ตรวจสอบการชำระเงิน (ลบหลัง 90 วัน)

ข้อมูลที่เก็บอัตโนมัติ

  • IP address — เก็บแบบ hash (SHA-256) เพื่อความปลอดภัย ไม่สามารถ reverse กลับเป็น IP ได้
  • ประวัติการสั่งซื้อ — รายการเพลงที่ซื้อ ยอดรวม สถานะออเดอร์
  • รายการโปรด + ไลค์ — เพลงที่ลูกค้ากด ❤️
  • ข้อมูลการยินยอม (consent) — บันทึกการยอมรับนโยบายฯ

2. วัตถุประสงค์การใช้ข้อมูล

เราใช้ข้อมูลของท่านเพื่อ:

  • ส่งมอบเพลงที่สั่งซื้อ + ลิงก์ดาวน์โหลด
  • ติดต่อเรื่องออเดอร์ผ่าน WhatsApp
  • ตรวจสอบการชำระเงิน (สลิป)
  • ปกป้องการทุจรต (fraud prevention) + กัน spam
  • ปฏิบัติตามกฎหมาย (เช่น เก็บ audit log ตามกฎหมายไทย)

เราจะไม่ ขายข้อมูลของท่านให้บุคคลที่สาม

3. ระยะเวลาการเก็บข้อมูล

  • ออเดอร์ + ใบเสร็จ: เก็บตลอดอายุการให้บริการ
  • สลิปการโอนเงิน: ลบหลัง 90 วัน
  • Audit log: เก็บ 10 วัน (ลบอัตโนมัติ)
  • Session: 30 วัน (ต่ออายุอัตโนมัติถ้า login บ่อย)
  • บัญชีลูกค้า: เก็บจนกว่าลูกค้าจะขอลบ

4. สิทธิ์ของท่านตาม PDPA (มาตรา 30-37)

ท่านมีสิทธิ์ดังต่อไปนี้ สามารถใช้ได้ผ่านหน้า "ตั้งค่าบัญชี":

  • สิทธิ์ได้รับแจ้ง — ท่านได้รับแจ้งผ่านนโยบายนี้
  • สิทธิ์เข้าถึง — ดาวน์โหลดข้อมูลทั้งหมดของท่านเป็น JSON
  • สิทธิ์แก้ไข — แก้ชื่อที่แสดง + เบอร์ WhatsApp
  • สิทธิ์ลบ — ลบบัญชี (soft delete + 30 วัน grace ก่อน hard delete)
  • สิทธิ์คัดค้าน — opt-out การรับข่าวสาร marketing
  • สิทธิ์เคลื่อนย้าย — export ข้อมูลเป็น JSON (เหมือนสิทธิ์เข้าถึง)

5. ความปลอดภัย

เราปกป้องข้อมูลของท่านด้วยมาตรการ:

  • รหัสผ่านเก็บแบบ PBKDF2 hash (100,000 iterations)
  • Session cookie แบบ HttpOnly + Secure
  • Rate limiting กัน brute-force (5 ครั้ง/15 นาที)
  • IP hash แทน IP จริง (กัน reverse)
  • HTTPS ทุกการเชื่อมต่อ
  • Audit log บันทึกทุกการแก้ไขข้อมูล

6. การใช้ Cookie

เราใช้ cookie เฉพาะที่จำเป็น:

  • Session cookie — จดจำการ login (30 วัน)
  • Cookie consent — จดจำว่าท่านยอมรับ cookie แล้ว (1 ปี)

เราไม่ใช้ third-party tracking cookie (เช่น Google Analytics, Facebook Pixel)

7. การแก้ไขนโยบาย

เราอาจแก้ไขนโยบายนี้ในอนาคต หากมีการเปลี่ยนแปลงสำคัญ เราจะแจ้งให้ท่านทราบผ่านทางเว็บไซต์

8. ติดต่อเรา

หากท่านมีคำถามเกี่ยวกับนโยบายนี้ หรือต้องการใช้สิทธิ์ PDPA ท่านสามารถ:

  • ติดต่อผ่าน WhatsApp (ปุ่มลอยด้านล่างซ้ายของหน้าเว็บ)
  • ใช้หน้า "ตั้งค่าบัญชี" ในระบบ (login ก่อน)
